## 🇷🇺
Эта сборка включает 70-90 модификации и 4-7 ресурспаков, значительно расширяя игровой опыт. Она создана специально для сервера "RomixerX" и включает функционал для управления и скрытия конфиденциальной информации.

Уникальные музыкальные композиции, возможность биндинга клавиш, смены скина тотема и его превращения в куклу. Есть функции приближения и отдаления объектов, а также PlasmoVoice и EmoteCraft для улучшенной коммуникации.

Модификации Chat Patches и Symbol Chat улучшают функционал чата, а подсказки о блоках и эффектах делают игру удобнее. Также доступны мини-карта и облегчённое управление инвентарем.

- Версии ниже новейшей будут помечаться как "Alpha".
- В дальнейшем планируются вкусные обновления. 


## 🇺🇸

This build includes 70-90 modifications and 4-7 resource packs, significantly expanding the gaming experience. It was created specifically for the RomixerX server and includes functionality for managing and hiding confidential information.

Unique musical compositions, the ability to bind keys, change the skin of the totem and turn it into a doll. There are functions for approaching and distancing objects, as well as PlasmoVoice and EmoteCraft for improved communication.

Modifications of Chat Patches and Symbol Chat improve the chat functionality, and hints about blocks and effects make the game more convenient. A mini-map, and easier inventory management are also available.

- Versions below the newest will be marked as "Alpha".
- Delicious updates are planned in the future.
